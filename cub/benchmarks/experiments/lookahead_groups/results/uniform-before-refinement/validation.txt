Compiler compatibility limit
  CUDA 12.0 cannot target SM120 and does not provide the PTX ISA 8.6 instructions
  used by lookahead scan. The CUDA 12.0 shifted-output run therefore checks the
  compatible legacy scan path and header compatibility. The separately instantiated
  squad test exercises the new group adapter on compute_90 PTX JIT. These checks do
  not establish lookahead-kernel support on CUDA 12.0.

Clang-tidy details
  Clang 23 supports CUDA Toolkit versions through 13.2 and parses the 13.5 headers
  with PTX ISA 9.2 for these checks. Only its unknown-toolkit-version warning is
  disabled; repository checks remain enabled. Device parsing uses __CUDA_ARCH__=1200.
  A single local NOLINTNEXTLINE(misc-const-correctness) on store_tile's refInOutS
  documents a template false positive: data() requires a mutable SmemRef when the
  store squad is active, even though a widening-output specialization omits that call.
  Applying the suggested const qualifier was verified to fail the noncommutative
  same-output-type compilation. No whole-file check suppression was used.
