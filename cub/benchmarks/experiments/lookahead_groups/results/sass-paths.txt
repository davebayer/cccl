WHAT CAUSED THE REMAINING OVERHEAD

The prior adapter first created group_as, dispatched through
with_static_unit_count, then dispatched again to a squad descriptor. That
structure required a runtime group rank and selected prefix, and exposed
count/descriptor combinations to the compiler before it could remove them.
The rank-only intermediate eliminated the selected-prefix value but kept the
group-rank and count/descriptor dispatch. Final dispatch instead selects the
descriptor from balanced thresholds on the cached uniform physical warp index.
Only that leaf constructs the typed count/rank mapping from Counts[Index].

The group_as expression still defines the partition. Debug checks compare
both selected ordinal and local warp rank against that mapping. Native cudax
identity-group synchronization and public rank queries remain. The positive
count/full-block/one-dimensional preconditions prove that the cached prefix
and static count describe the same group. Descriptor IDs remain independent
of slots; reversed-ID tests exercise that distinction. The native barrier
constructor copies its ID, so no pointer to a leaf-local ID escapes.

with_static_unit_count is unnecessary once the selected leaf already knows
its count from the index_sequence. Removing that outer specialization avoids
compiling impossible count/descriptor callback combinations and lets NVCC
eliminate mapper-result materialization from the optimized entry path.

Prior reducer warps 0..3 execute 10 uniform entry instructions, rank-only 8,
and final 5. Scanner warps 4..7 execute 14 prior, 11 rank-only, and 5 final.
The baseline executes 5 in both cases. Counts include the resource-offset
UIADD shared by these paths plus taken/not-taken branches. The final path
needs no dense group-rank UMOV/USEL sequence, selected-negative-prefix values,
or dynamic prefix UIADD. Branches use the same cached warp-uniform rank as
baseline, so no new collective or divergent rank-reconstruction step appears.

The rank-only stage specifically removed four UMOVs for prefixes 0/-4/-8/-9,
one USEL for -9/-10, and the local-rank UIADD from the static prologue. Whole-
kernel schedules added two MOVs elsewhere, leaving 3 fewer non-NOP instructions
in each of eight kernels and a 24-instruction aggregate reduction. Its int-
inclusive padded size stayed 1,528. Final structural dispatch reduces that
kernel to 1,496, matching the original baseline.

RESOURCES AND VALIDATION

Final main/optional sum kernels retain 86-89 registers, 3 barriers, no stack
and no spills. Affine main uses 96/95 registers versus rank-only 96/93;
optional uses 93/95 in both. Sum register allocation/CTA shared memory did not
change; shared memory already limits these kernels to one resident CTA.

Reviewed overlay and landed bytes are identical. Both complete main/optional
harnesses passed GPU correctness. Debug squad checks passed CUDA 13.5/GCC 13
and CUDA 12.0/GCC 7 in C++17: single, uniform, uneven, 1024-thread, subrange,
and permuted descriptor-ID layouts. Independent review verified count/prefix
equivalence and native barrier-ID lifetime. Full header host/device clang-tidy
and post-land pre-commit passed. Root also validated 26,586 Catch2 assertions
and the shifted-output/legacy/shared-helper smoke tests against this overlay.
Final source-hashed preflight, event timings and NCU profiles are authoritative
and are recorded in the main report.

The binary mapper alone with the previous squad produced 32,912 optional
instructions and 15 indirect branches; adding the rank rebind produced
35,464 optional instructions and 20 indirect branches. Double/affine pipeline
bodies were repeated despite unchanged register/shared-memory allocations.
Explicit constexpr role pruning made that candidate healthy, but the final
structural change reaches better code without modifying generic mapping or
adding role indices to squad types. No role/type-index change remains.

A CUB-only temporary overlay initially reported 13,248 for a prefix rebind,
but it still read a changing working-tree cudax header. It did not isolate the
linear mapper. Source-hashed preflights and an exact staged-mapper overlay
corrected that attribution. Generic lane-mask ternary and if-constexpr lambda
forms both produced 13,448/13,808 with the rank-only squad; the style rewrite
did not explain the difference. The original ternary is restored with precise
lint annotations and its non-comment code tokens match the staged mapper.

- separate descriptor-local thread-unit view: some size reduction, but
