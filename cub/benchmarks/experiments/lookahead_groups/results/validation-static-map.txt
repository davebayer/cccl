Known pre-existing caveat, not caused or changed by this refinement:
  Directly applying exhaustive map() to an invalid previous mapping result
  returns an exhaustive result's invalid sentinel. That result's is_valid()
  is unconditionally true by its exhaustive type contract. Invalid previous
  propagation is therefore validated through the nonexhaustive overload;
  exhaustive composition is tested only on valid previous results. Public
  group construction supplies a valid initial previous mapping.
