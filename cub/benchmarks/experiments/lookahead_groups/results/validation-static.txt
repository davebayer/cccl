Compatibility limit
  CUDA 12.0 cannot target SM120 or compile the PTX ISA 8.6 lookahead body.
  Its full scan harness and shifted-output test therefore validate header/legacy
  scan compatibility, not lookahead execution. The separate squad.cu binary
  actually instantiates static group_as/index_sequence and with_static_unit_count
  on compute_90 PTX and executes the new adapter through the driver's JIT.

Clang-tidy frontend note
  Clang 23 officially recognizes CUDA Toolkit versions through 13.2, while these
  checks parse the installed 13.5 headers with PTX ISA 9.2. Only its
  unknown-toolkit-version warning is disabled. Repository checks stay enabled.
  The pre-existing, specifically documented mutable-SmemRef template false
  positive suppression in store_tile is described in validation.txt.
